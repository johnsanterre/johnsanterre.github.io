Week 2: reading code you did not write

Week 2: code lezen die je niet zelf schreef

Every analysis that a ministry, a business or a family in Suriname relies on runs on code, and someone has to be able to read that code and vouch for it. In the second week, students learn to read code before they run it: they predict its output, check the unit of every number, find where a program starts and follow one value through it. The second project asks what Suriname sells to the world and how much of it is gold. It ends in a one-page brief for a ministry official who weighs how much the country's export earnings rest on one kind of good.

Elke analyse waarop een ministerie, een bedrijf of een gezin in Suriname vertrouwt, draait op code, en iemand moet die code kunnen lezen en ervoor instaan. In de tweede week leren studenten code lezen voordat ze hem uitvoeren: ze voorspellen de uitvoer, controleren de eenheid van elk getal, zoeken waar een programma begint en volgen één waarde erdoorheen. Het tweede project vraagt wat Suriname aan de wereld verkoopt en hoeveel daarvan goud is. Het eindigt in een notitie van één pagina voor een ambtenaar van een ministerie die afweegt hoeveel de exportinkomsten van het land op één soort goederen rusten.
