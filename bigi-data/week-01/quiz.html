After part 1: A notebook is a workbenchNa deel 1: Een notebook is een werkbank

QuestionVraag 1

You open a notebook fresh and press play on a cell near the bottom that prints a name defined in a cell near the top. What happens?

Je opent een notebook opnieuw en drukt op afspelen bij een cel onderaan die een naam afdrukt die in een cel bovenaan is gedefinieerd. Wat gebeurt er?

  1. It prints the name, because the defining cell is higher on the page.De naam wordt afgedrukt, omdat de definiërende cel hoger op de pagina staat.
  2. It prints a NameError, because the defining cell has not run yet.Er verschijnt een NameError, omdat de definiërende cel nog niet is uitgevoerd.
  3. It runs the cells above it first and then prints the name.Het voert eerst de cellen erboven uit en drukt dan de naam af.
Show the answerToon het antwoord

The second answer is right. The notebook remembers what ran, not what is written, and nothing has run yet, so the name is not in memory. The first answer trusts the page order, which the notebook never reads. The third describes restart and run all, which you must ask for; a single play button runs one cell only.

Het tweede antwoord klopt. Het notebook onthoudt wat is uitgevoerd, niet wat er staat, en er is nog niets uitgevoerd, dus de naam zit niet in het geheugen. Het eerste antwoord vertrouwt op de volgorde op de pagina, en die leest het notebook nooit. Het derde beschrijft herstarten en alles uitvoeren, waar je zelf om moet vragen; één afspeelknop voert maar één cel uit.

  2. It empties the memory and runs every cell from the top in page order.Het leegt het geheugen en voert elke cel van boven naar beneden uit in paginavolgorde.
  3. It runs only the cells that have changed since the last run.Het voert alleen de cellen uit die sinds de laatste keer zijn veranderd.
Show the answerToon het antwoord

The second answer is right, and it is the finishing habit of this part: if the notebook runs clean from the top, the page and the memory agree. The first is wrong because the page is never touched; only the memory is cleared. The third describes something no notebook does; it cannot know which cells drifted, which is exactly why it runs them all.

Het tweede antwoord klopt, en dit is de afsluitende gewoonte van dit deel: als het notebook schoon van boven naar beneden draait, komen pagina en geheugen overeen. Het eerste is fout omdat de pagina nooit wordt aangeraakt; alleen het geheugen wordt gewist. Het derde beschrijft iets wat geen enkel notebook doet; het kan niet weten welke cellen zijn afgedreven, en daarom voert het ze juist allemaal uit.

QuestionVraag 1
