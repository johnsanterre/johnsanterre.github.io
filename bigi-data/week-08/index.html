Week 8: version control and sharing work

Week 8: versiebeheer en werk delen

Work that only one person can find or rerun cannot serve a ministry, a business or a community group for long. In the last week of month 2, students learn to keep a project in a git repository, write a history and a README that a stranger can follow, and share work with a team without losing anyone's commits. The project asks how fast Suriname came online. Each team publishes its answer as a repository on GitHub, with a note for a ministry that plans to move a public service online.

Werk dat maar één persoon kan vinden of opnieuw kan draaien, helpt een ministerie, een bedrijf of een buurtorganisatie niet lang. In de laatste week van maand 2 leren studenten een project bij te houden in een git-repository, een geschiedenis en een README te schrijven die een buitenstaander kan volgen, en werk te delen met een team zonder iemands commits kwijt te raken. Het project vraagt hoe snel Suriname online kwam. Elk team publiceert zijn antwoord als repository op GitHub, met een notitie voor een ministerie dat een openbare dienst online wil brengen.
