Lecture Uploader, a private API client

Last updated 9 September 2026

Lecture Uploader is a private command line tool with one user, who is also its author. It is not distributed, sold, or offered as a service to anybody. These terms exist because the YouTube API Services Terms of Service require an API client to publish them.

1. What this client is

Lecture Uploader is a command line program written and operated by John Santerre. It uploads video files from a personal computer to the YouTube channel that authorises it, setting a title, description, tags, and privacy status for each.

The videos are recorded lectures for university courses the author teaches. The author produced them, holds the rights to them, and uploads them to his own channel.

2. Who may use it

The author, and nobody else. The client is not published, has no installer, no account system, and no interface for a second person. If that changes, these terms will be rewritten before it does.

3. YouTube API Services

This client uses the YouTube API Services. By authorising it you are also agreeing to the YouTube Terms of Service. Google's handling of data on its side is described in the Google Privacy Policy.

The client requests one scope, https://www.googleapis.com/auth/youtube.upload, and requests no other.

4. What the client will not do

  • It will not collect, store, or process data about YouTube users.
  • It will not scrape, index, or bulk-download YouTube content.
  • It will not access any channel other than the one that authorised it.
  • It will not sell, share, or transfer authorised data to any third party.
  • It will not be used to circumvent any YouTube feature, policy, or restriction.
  • It will not display advertising or be operated for commercial gain.

5. Content

The author is responsible for the videos uploaded and warrants that he holds the necessary rights to them. Uploaded content is subject to YouTube's Community Guidelines and to YouTube's own moderation, over which this client has no influence.

6. Revoking access

Authorisation may be withdrawn at any time at https://myaccount.google.com/permissions, without notice and without contacting the author. The client stops working immediately.
