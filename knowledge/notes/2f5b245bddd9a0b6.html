Abstraction: DeepSeek R1 1.5B distilled model runs locally on sub-$250 edge hardware

Key points:

  • DeepSeek R1 distilled 1.5B Qwen model runs on NVIDIA Jetson Nano with an Ollama backend and WebUI
  • Jetson Nano specs: 128-core Maxwell GPU, 4GB LPDDR4, quad-core ARM Cortex-A57, up to 472 GFLOPS (FP16), 5-10W power
  • Jetson Nano pricing ranges from ~$219-$400 new; older versions available on eBay for ~$99
  • FP16 version of DeepSeek R1 1.5B tested and compared favorably against Mini Llama 3.1 1B
  • Demonstrates viability of running capable reasoning models on inexpensive embedded AI hardware

Connections: Deepseek · Nvidia · Large Language Models · Edge Inference · Model Distillation
