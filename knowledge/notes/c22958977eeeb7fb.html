Super Nested Claude Code Offers Next Level Vibe Coding

Abstraction: Nested Claude Code instances coordinated via tmux for parallel workflow automation

Key points:

  • System uses a central controller to manage multiple tmux terminals, each running a dedicated Claude Code instance on an assigned subtask, enabling parallel execution of complex workflows
  • Dynamic task allocation: tasks are assigned to terminals by complexity/priority; integration with Claude Opus provides detailed task instructions per terminal
  • Demonstrated creating a procedural galaxy in Three.js using 6 tmux terminals (rendering, UI, object generation), and visualizing micro GPT training with 4 terminals
  • Developer defines only a high-level goal; system autonomously plans, decomposes, and executes steps — real-time monitoring via activity logs
  • Currently macOS-only (tmux dependency); open-source but requires solid configuration knowledge; no Windows/Linux support yet
