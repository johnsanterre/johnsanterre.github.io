Calculator for eigenvalues and eigenvectors

eigenvalueseigenvectorscalculatorlinear-algebra

Abstraction: Interactive web tool computing eigenvalues and eigenvectors for matrices

Key points:

  • Computes characteristic polynomial, eigenvalues, and eigenvectors for arbitrary square matrices
  • Accepts fractions and complex number inputs (e.g., -3+7/5i)
  • Separate calculator mode for determining matrices from a given eigensystem
  • Also covers linear maps, quadrics, and principal component analysis in R² and R³
  • Exact-mode computation implemented in JavaScript; Java modes available for larger matrices

Connections: Eigenvalues · Numerical Linear Algebra
