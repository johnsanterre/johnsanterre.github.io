An Honest Review of Google Antigravity

google-antigravitygeminiagent-manageride-reviewagentic-ide

Abstraction: Honest developer review of Google Antigravity agent-first IDE

Key points:

  • Google Antigravity is a VS Code fork (OSS) with references to Windsurf's "Cascade" agent in the codebase, suggesting Google acquired technology or personnel from Windsurf
  • Three core surfaces: Editor (code), Browser (controlled Chrome instance with AI cursor), and Agent Manager (external "inbox" window showing parallel projects/agent status)
  • Gemini 3 one-shot built a working Insaniquarium clone including self-generated sprite assets; the same task burned 3.5M tokens in Codex High and produced a broken result
  • Browser Agent records video walkthroughs and captures screenshots of errors during automated testing sessions
  • Significant bugs: broken extensions (Svelte), missing arrow-key navigation, no Git Worktrees, input lag from glow animation, heavy resource drain; "Review Code" button closes instantly
  • Free tier resets every 5 hours with access to Gemini 3; not yet stable enough to replace Cursor for production deadlines
