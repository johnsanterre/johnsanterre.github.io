Abstraction: Hands-on vibe coding experiment building a game with Claude 3.7 Sonnet

Key points:

  • Author used Claude 3.7 Sonnet to build a word-typing cascade game through 14 conversational iterations with no direct code editing
  • First two attempts failed silently (broken start button); bugs were fixed by describing behavior in natural language, not inspecting code
  • Practical adjustments (mixed real/made-up words instead of full dictionary) kept scope achievable; shipped a playable, shareable game
  • Key lessons: rapid prototyping works; iteration is essential; simplify requirements incrementally; output lacks professional polish and optimization
  • Quality ceiling is real: functional but not production-ready; no mobile support; not suitable for complex, polished products
  • Analogy drawn to Flappy Bird: simple ideas with AI can still produce widely enjoyed results without sophisticated architecture
