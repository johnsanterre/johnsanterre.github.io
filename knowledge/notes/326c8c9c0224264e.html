BearID: Face recognition for brown bears - Raspberry Pi

face-recognitionwildlife-monitoringdeep-learningcomputer-visionraspberry-pi

Abstraction: Deep learning bear face recognition for wildlife conservation monitoring

Key points:

  • BearID identifies individual brown bears by face and ears — the least-changeable features across seasons — using deep learning adapted from Dlib's dog-face model (transfer learning)
  • Built by ARM engineer Ed Miller and partners; runs training on Microsoft Azure (AI For Earth grant), field analysis on Raspberry Pi 4B
  • Dataset covers 150+ bears at Katmai National Park, Alaska and Knight Inlet, British Columbia
  • Goal is to expand the pipeline to all 8 bear species, including Andean bears in South America where human-wildlife conflict is a concern
  • Future vision: in-camera detection with low-power wireless transmission for real-time population tracking without sending images to the cloud
