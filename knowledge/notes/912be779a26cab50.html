Topology 101: The Hole Truth

topologyalgebraic-topologyhomologybetti-numbers

Abstraction: Introduction to how topologists formally count holes via homology and Betti numbers

Key points:

  • Topology studies shapes up to continuous deformation (stretching/bending), unlike geometry which preserves rigid measurements
  • Euler's formula V-E+F=2 for convex polyhedra is topological, not geometric; holes change this constant (donut: V-E+F=0)
  • Riemann defined holes by maximum cuts without disconnecting a surface; Poincaré generalized this to all dimensions via homology (1895)
  • Betti numbers count n-dimensional holes: b0 = connected components, b1 = circular holes, b2 = enclosed cavities; Euler number = b0-b1+b2
  • Persistent homology enables real-world applications: detecting sensor coverage gaps, mapping political islands in election data
