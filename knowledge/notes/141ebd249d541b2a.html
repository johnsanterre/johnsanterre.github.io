Abstraction: JavaScript-embedded probabilistic programming language for Bayesian modeling

Key points:

  • WebPPL is a feature-rich probabilistic programming language embedded in JavaScript, installable via npm
  • Created by Noah Goodman and Andreas Stuhlmüller; companion to the web book "The Design and Implementation of Probabilistic Programming Languages" (dippl.org)
  • Open source under MIT license; supports both browser-based applications and command-line use
  • Related resources include "Probabilistic Models of Cognition" (probmods.org) and "Modeling Agents with Probabilistic Programs" (agentmodels.org)
  • Funded by DARPA (FA8750-14-2-0009) and the Office of Naval Research (N00014-13-1-0788)
