Abstraction: Companion site for Hadley Wickham's Advanced R book

Key points:

  • "Advanced R" by Hadley Wickham (Chapman & Hall) targets R users wanting to deepen programming skills and understand R's internals
  • Foundations section covers data structures, subsetting, functions, OO systems, environments, and debugging
  • Functional programming section covers higher-order functions, functionals, and function operators
  • Metaprogramming section covers non-standard evaluation, expressions, and domain-specific languages in R
  • Performance section covers profiling, memory management, Rcpp (C++ integration), and R's C interface
  • All content freely available on companion website; pairs with "R Packages" book by same author
