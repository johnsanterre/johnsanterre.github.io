Abstraction: Jekyll Liquid variable reference for site, page, and paginator

Key points:

  • Global variables: site (config + collections), page (current file), layout (current layout), jekyll (version/env), content (rendered body in layouts)
  • site.* exposes all _config.yml keys plus site.posts, site.pages, site.collections, site.data, site.tags, site.categories
  • page.* includes title, url, date, id, categories, tags, path, slug, ext, next, previous; custom front matter keys also accessible as page.custom_key
  • layout.* exposes front matter from the current layout file
  • Paginator variables (page number, per_page, posts, total_posts, total_pages, previous/next path) available only in index files
  • jekyll.version and jekyll.environment expose build metadata; theme.* exposes gem-based theme metadata (version, authors, description)

Connections: Jekyll · Liquid · Static Site Generation · Template Language

Source: http://jekyllrb.com/docs/variables/
