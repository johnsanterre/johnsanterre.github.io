Google Workspace Updates: New community features for Google Chat and an update on Currents

google-chatgoogle-workspaceenterprise-communicationgoogle-currents

Abstraction: Google Currents shutdown and Google Chat spaces community feature expansion

Key points:

  • Google Currents (enterprise Google+) being wound down; data export via Takeout required before August 8, 2023; automated migration to Google Chat spaces available
  • Google Chat spaces scaled to 8,000 members per space; searchable via Gmail; invite via link
  • New features in 2022-2023: inline threading, custom emojis, announcements (admin-only posting), DLP (data loss prevention)
  • Space managers role added for moderation and membership management; Google Groups integration planned for membership management
  • Third-party integrations added: Jira, GitHub, Asana, PagerDuty, Zendesk, Salesforce; AppSheet enables no-code Chat app building
