Adoptium

javaopenjdkadoptiumeclipse-temurinopen-sourcejdk

Abstraction: Eclipse Adoptium providing free certified OpenJDK binaries via Temurin

Key points:

  • Eclipse Temurin is the OpenJDK distribution from Adoptium — TCK-certified (Java SE) and AQAvit-verified for production use
  • Adoptium Working Group promotes high-quality, certified runtimes for the broader Java ecosystem
  • Builds are AQAvit-verified for performance, reliability, and security; supply chain is built with robust security standards
  • Provides cross-platform consistency across all major operating systems and hardware architectures
  • Community-driven development backed by enterprise-grade commercial supporters for long-term sustainability
  • Adoptium also provides open-source CI/build infrastructure and extensive QA tests usable by other runtime builders

Connections: Eclipse Adoptium · Eclipse Foundation · Open Source Software · Java Runtime
