Running Python and R inside Emacs

emacsorg-modeliterate-programmingpythonr

Abstraction: Emacs org-mode babel executing code blocks inline with output

Key points:

  • org-mode lets you embed, execute, and display output of source code blocks inside plain-text documents
  • Supports 35+ languages; blocks delimited by #+begin_src <lang> / #+end_src; run with C-c C-c
  • Python requires an explicit return statement to produce a value; R returns implicitly
  • Use :results output :session to capture multi-line REPL-style output including print statements
  • Only Emacs Lisp is enabled by default; other languages must be activated via org-babel-do-load-languages
  • Underpins literate programming and reproducible research workflows (see J. Stat. Software v46/i03)

Connections: Emacs · Python · R Language · Literate Programming · Org Mode · Reproducible Research
