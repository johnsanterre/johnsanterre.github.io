AMD Radeon RX 7800 XT Desktop graphics card review: More affordable GeForce RTX 4070 performance

gpuamdgraphics-cardbenchmarkgaming

Abstraction: AMD RX 7800 XT RDNA3 GPU targets 1440p gaming at $499 versus RTX 4070

Key points:

  • Navi 32 XT chip: 3,840 shader units, 16 GB GDDR6, 256-bit memory bus (620.8 GB/s bandwidth), 263 W TDP, priced at $499 / 552 EUR
  • Uses chiplet design: one GCD (200 mm2) plus four MCDs (36.6 mm2 each) for VRAM connectivity
  • Synthetic benchmarks place it slightly ahead of RTX 4070; AMD itself names RTX 4070 as the direct competitor
  • DisplayPort 2.1 support (3x DP 2.1 + 1x HDMI 2.1a) — Nvidia RTX 4000 series does not offer DP 2.1
  • Underperforms vs. AMD's own RX 7900 GRE by ~9% in synthetic tests; intra-AMD competition is a weakness for the lineup
  • Intended as successor to RX 6800; reference design is 27 cm long and fits compact cases
