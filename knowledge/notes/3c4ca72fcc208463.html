I created over a dozen personal apps using AI in 60 days, here's what I learned

ai-codingno-codevibe-codingapp-developmentbolt

Abstraction: Non-programmer builds 15+ apps using Claude Sonnet and Bolt.new

Key points:

  • Author (non-coder journalist) built 15+ personal apps in 60 days using Claude Sonnet 3.5 via Bolt.new, including an image background remover, QR code creator, and book inventory scanner
  • Claude Sonnet 3.5 identified as the dominant coding model powering nearly all AI coding tools; described as "absolute emperor of coding"
  • Bolt.new wraps Claude in an easy interface with one-click Netlify deployment; Bolt.diy (open-source) used for cheaper experimentation
  • Other tools tested: Tempo, Pythagora, Marblism, GitHub Spark, WindSurf, CodeCompanion
  • Key lessons: start simple, learn basic tech fundamentals (file structures, databases, auth), choose tools with easy deployment
  • Mark Zuckerberg predicted AI could replace mid-level software engineers; Google Sundar Pichai reported AI generates 25% of Google's code

Connections: Anthropic · Claude · Bolt · Agentic Coding · Prompt Engineering
