AudioPen is a great web app for converting your voice into text notes | TechCrunch

Abstraction: Voice-to-text note-taking web app powered by OpenAI Whisper

Key points:

  • AudioPen by Louis Pereira uses OpenAI Whisper for transcription then GPT-style cleanup into readable notes
  • Free tier: 3-minute recordings, 10 stored notes; premium is $60/year or $120 lifetime
  • Premium features: 15-minute recordings, unlimited cloud storage, 30 audio file uploads/month, auto-summaries, multilingual support, style library
  • "Super Summary" feature aggregates multiple notes on the same topic
  • Chrome extension released to capture notes from any browser tab without visiting the site
  • Useful for non-native English speakers wanting to capture thoughts in clean English
