Key points:

  • PyCon is the largest annual gathering for the Python open-source community
  • Offers multi-hour tutorials by experienced instructors prior to main conference days
  • Development sprints run up to four days after the main conference for open-source project contributors
  • PyCon 2016 chaired by Brandon Rhodes
