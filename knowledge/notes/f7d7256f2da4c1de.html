I Tested (New) Claude Code /Insights (It Roasted My Coding Habits)

claude-codeinsightsdeveloper-analyticsworkflow-analysiscoding-habits

Abstraction: Claude Code /insights command analyzes 30-day coding history into personalized report

Key points:

  • /insights command reads the user's Claude Code message history from the past 30 days and generates an interactive HTML report
  • Report covers: strengths and successful patterns, friction points and hindrances, project breakdowns, tool usage patterns, and personalized workflow improvement suggestions
  • Some users reported extreme usage stats: one developer logged 2,200 hours and 3,625 sessions in a single month
  • The command surfaces repeated mistakes developers didn't realize they were making, giving blunt actionable feedback ("roasting" coding habits)
  • Report is interactive HTML, not just text — designed for browsing and self-reflection on development patterns

Connections: Claude Code · Anthropic · Agentic Coding · Developer Tools
