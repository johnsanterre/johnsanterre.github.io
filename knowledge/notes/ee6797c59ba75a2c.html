I use Docker containers for everything now, and they are the most boring but incredible software I run

dockerself-hostedpi-holehome-assistantpaperless

Abstraction: Docker containers as reliable portable infrastructure for self-hosted home services

Key points:

  • Pi-hole in Docker provides network-wide ad blocking at the DNS level across all devices without per-device browser extensions; migration is as simple as moving docker-compose.yml and volume data
  • Paperless-ngx container uses OCR to make every document word-searchable; auto-tags documents by learned visual patterns (logos, senders) and eliminates physical file management
  • Home Assistant consolidates previously siloed smart home apps into a single local-first dashboard; cross-brand Zigbee/smart plug compatibility with automation rules
  • Firefly III double-entry bookkeeping tracks every expense and subscription locally; revealed three unused streaming subscriptions when all recurring charges were listed together
  • Key theme: Docker enables a portable private cloud where personal data stays local, configuration is reproducible, and software is "boring" — meaning stable and dependable

Connections: Docker · Home Assistant · Containerization · Self Hosting
