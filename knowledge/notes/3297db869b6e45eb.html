Introducing Amazon Bio Discovery | Amazon Web Services

drug-discoverybiotechai-biologylab-in-the-loopaws

Abstraction: AWS agentic platform for lab-in-the-loop drug discovery

Key points:

  • Amazon Bio Discovery integrates 40+ AI biology models with AI-guided selection, no-code workflow building, and wet-lab CRO partners (Ginkgo Bioworks, Twist Bioscience, A-Alpha Bio)
  • Collaboration with Memorial Sloan Kettering used the platform to design ~300,000 novel antibody candidates, filter to top 100,000, and send to wet lab in weeks vs. up to a year traditionally
  • Lab-in-the-loop cycle: in silico design → CRO wet-lab validation → results flow back to fine-tune models with active learning
  • Computational biologists build reusable no-code workflow recipes; bench scientists configure and run experiments via agentic assistance without custom code
  • Built on AWS infrastructure used by 19 of the top 20 pharmaceutical companies; data isolation keeps proprietary models and experimental data protected

Connections: Amazon Web Services · Ginkgo Bioworks · Memorial Sloan Kettering · AI Agents · Drug Discovery · Computational Biology · Active Learning
