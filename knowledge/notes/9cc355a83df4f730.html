Building your first Jekyll site in 5 minutes

jekyllstatic-siterubyweb-developmenttutorial

Abstraction: Beginner tutorial building static HTML sites with Jekyll Ruby gem

Key points:

  • Jekyll is a Ruby gem that compiles template files and content (Markdown/Textile/HTML) into static HTML at deploy time, eliminating runtime scripting
  • Required directory structure: _layouts/ (templates), _posts/ (content files), _site/ (compiled output), plus _config.yml
  • Post filenames must start with YYYY-MM-DD date format; YAML Front Matter in each file specifies layout and metadata
  • Templates use Liquid-style {{ content }} holes; layouts can nest (post.html wraps in default.html)
  • Run jekyll --server to spin up a local preview server at localhost:4000
