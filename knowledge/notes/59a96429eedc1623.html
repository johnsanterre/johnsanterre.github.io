Stanford Large Network Dataset Collection

graph-datasetsnetwork-sciencebenchmarkssocial-networks

Abstraction: SNAP repository of large real-world network graph datasets

Key points:

  • Covers social (Facebook 4k nodes, LiveJournal 4.8M nodes), citation, collaboration, web, road, P2P, and temporal networks
  • Includes signed, weighted, temporal, attributed, and bipartite graph variants
  • Review datasets: Amazon (34.7M reviews), BeerAdvocate, RateBeer, movie reviews
  • Temporal networks include Stack Overflow (63.5M edges), Wikipedia talk (7.8M edges)
  • Canonical citation: Jure Leskovec and Andrej Krevl, SNAP Datasets, 2014
  • Also includes graph-level datasets (ego-nets, Reddit threads, Twitch, GitHub stargazers)

Connections: Stanford University · Snap · Network Analysis · Graph Datasets
