Abstraction: R package teaching infectious disease epidemiology via simulation apps

Key points:

  • DSAIDE is an R package with GUI-based simulation apps teaching infectious disease epidemiology from a dynamical systems perspective; no coding required by default
  • Install with install.packages('DSAIDE'), launch with dsaidemenu(); also available online via Shiny
  • Published in PLoS Computational Biology (doi:10.1371/journal.pcbi.1005642); supported by NIH grants including U19AI117891
  • Companion package DSAIRM covers within-host infection dynamics with the same structure
  • Developed and maintained by Andreas Handel at UGA; instructors can request solutions and quiz sheets
  • Allows users to go beyond the GUI and directly modify simulations
