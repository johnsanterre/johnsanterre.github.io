Abstraction: Open-source platform providing 600+ tool integrations for AI agents via MCP

Key points:

  • ACI.dev connects 600+ pre-built integrations (Slack, Google Calendar, Vercel, Supabase, Cloudflare, etc.) to any AI agent via direct function calls or a Unified MCP server
  • Provides multi-tenant OAuth authentication, secrets management, natural language permission boundaries, and dynamic tool discovery to avoid overwhelming LLM context windows
  • "VibeOps" concept: agentic IDE + ACI integrations enables AI to handle DevOps tasks (provisioning, deployment, database configs, debugging) turning vibe-coded prototypes into live products
  • Framework and model agnostic; Python and TypeScript SDKs available; fully open source under Apache 2.0
  • Use cases include personal assistant chatbots, research agents, outbound sales automation, and customer support agents
  • Separate aci-mcp repo provides the standalone Unified MCP server built on the platform
