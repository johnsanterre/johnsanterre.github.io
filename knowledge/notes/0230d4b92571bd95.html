Antigravity 3 Hands-On with Security Mode: Turbo, Auto, Off, Plus New Skills

google-antigravityskillssecure-moderate-limitsagentic-ide

Abstraction: Google Antigravity 3 features customizable Skills, Secure Mode, and tiered access

Key points:

  • Customizable "Skills" are on-demand workflows/agents scoped globally or per workspace, distinct from always-active "Rules"; ideal for automating code reviews, deployments, and documentation
  • New rate limit system uses weekly quotas (replacing 5-hour refresh) with consumption tied to task complexity measured in "thinking tokens"
  • Three pricing tiers: Free (includes Opus 4.5 and Gemini 3 Pro), Pro at $20/month (2TB Drive, rate-limited), Ultra at $200/month (unlimited)
  • Secure Mode introduces three terminal permission levels: Turbo (fast, minimal oversight), Auto (balanced), and Off (manual approval for every action); allow/deny lists also available
  • Pro-tier stricter rate limits sparked debate among high-frequency users
