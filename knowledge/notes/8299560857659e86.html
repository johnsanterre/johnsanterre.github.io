Liquid for Designers

liquidtemplate-languageshopifyjekyllfilters

Abstraction: Shopify Liquid template language syntax and filter reference

Key points:

  • Two markup types: output {{ expression }} (renders a value) and tag {% logic %} (no output)
  • Filters transform output via pipe syntax: {{ 'hello' | upcase }} — 40+ built-ins including append, date, join, sort, truncate, url_encode, split, map, uniq
  • Filters chain left to right; each filter's output feeds the next
  • Control flow: if/elsif/else/unless, case/when; no not operator; no parentheses for precedence
  • Loop tag for iterates arrays, hashes, or integer ranges; supports limit, offset, reversed; helper vars forloop.index, forloop.first, forloop.last
  • Variables set with assign; multi-line string capture with {% capture varname %}...{% endcapture %}
