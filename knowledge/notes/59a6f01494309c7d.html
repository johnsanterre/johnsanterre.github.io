Abstraction: tmux commands and configuration for session, window, and pane management

Key points:

  • Sessions separate work environments: tmux new -s name, attach -t name, detach (prefix+d), list-sessions
  • Windows are named tabs within a session: new-window (prefix+c), select-window (prefix+0-9), rename-window (prefix+,)
  • Panes split windows: split-window (prefix+") for vertical, -h flag (prefix+%) for horizontal; swap with swap-pane -[UDLR]
  • Recommended config: remap prefix from Ctrl+b to Ctrl+a; bind r to source-file ~/.tmux.conf; bind ^A to cycle panes
  • Useful diagnostic commands: tmux list-keys, tmux list-commands, tmux info
  • Typical workflow: one session with multiple named windows (per project/context); 75/25 split for editor and terminal
