Building with Gemini 3 in Jules

geminijulesagentic-codinggooglecoding-agent

Abstraction: Gemini 3 Pro integration into Jules autonomous coding agent

Key points:

  • Gemini 3 Pro rolling out to Jules for Google AI Ultra subscribers first, then Pro plan
  • Gemini 3 surpasses Gemini 2.5 Pro at both agentic workflows and complex zero-shot coding tasks
  • Improvements in Jules: clearer reasoning, stronger intent alignment, multi-step tasks stay coherent with less user management
  • Jules available across terminal (Jules Tools), Gemini CLI extension, and Jules API — all surfaces share the same project view so context is preserved when switching
  • Goal stated as "always-on agent available everywhere you work" that handles volume and complexity of real software projects
  • Design philosophy: a good developer tool creates more space to think and reduces tool management overhead

Connections: Google · Gemini · Jules · Agentic Coding · AI Agents
