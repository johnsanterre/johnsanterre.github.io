Unauthorized "David Attenborough" AI clone narrates developer's life, goes viral

voice-cloningmultimodal-aiviraldeepfakeopenai

Abstraction: GPT-4V plus ElevenLabs creates unauthorized celebrity voice clone

Key points:

  • Replicate developer Charlie Holtz combined GPT-4 Vision (GPT-4V) and ElevenLabs voice cloning to impersonate David Attenborough narrating his life via webcam
  • A Python script called "narrator" captures a webcam frame every five seconds, sends it to GPT-4V via API with an Attenborough-style prompt, then pipes the text to ElevenLabs
  • The X post garnered over 21,000 likes within a day; Holtz published the code on GitHub
  • Both OpenAI and ElevenLabs API tokens are required, incurring real costs to run
  • The demo is unauthorized — Attenborough did not consent to having his voice cloned
